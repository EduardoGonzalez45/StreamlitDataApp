# StreamlitDataApp 

🔭 App that utilizes Streamlit's library to create an interactable website. This app uses NASA's Astronomy Picture of the Day API. 

🧾 Dependencies are within the requirements.txt file. 

## Within the app, you will be able to: 
* Input a date to pick a Picture of the Day from as far back as 10 years ago. 
* View the title lengths of the last 30 APODs.
